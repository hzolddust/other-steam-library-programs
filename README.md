# Steam Library Management Apps Source Codes
- *NexoGameST,*
- *RoxenTech,*
- *RedX,*
- *Nexa*

**To use these apps you need to install node.js and then using the npm command (JavaScript Runtime) the stages are listed below.**

**- cd nexogamest/roxen/nexa-source/redx**,

**- npm install**,

**- npm start**,

With this way you can easily use theese ***steam library management*** apps. If you want to create your own *app* you can use these as *template*.
